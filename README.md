# GoalPulse — Goal Setting & Tracking Portal

# Overview

GoalPulse is a role-based employee goal management and tracking portal developed for AtomQuest Hackathon 2026.

The platform digitizes the entire employee goal lifecycle including:

* Goal creation
* Goal approval
* Quarterly check-ins
* Team tracking
* Performance analytics
* Admin monitoring

#Features

* Employee Goal Creation
* Manager Approval Workflow
* Quarterly Check-ins
* Analytics Dashboard
* Team Performance Tracking
* Admin Panel
* Role-based Access

# User Roles

1. Employee
2. Manager
3. Admin

# Tech Stack

* HTML
* CSS
* JavaScript
